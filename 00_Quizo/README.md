# Quizo

<p align="center">

**A Modern Quiz Platform for Interactive Learning**

A full-stack quiz application that provides an engaging learning experience through multiple quiz categories, real-time scoring, leaderboards, achievements, and personalized user analytics.

</p>

---

## Overview

Quizo is a full-stack web application built using **Node.js, Express.js, MongoDB, and EJS**. The platform is designed to make learning interactive by allowing users to participate in quizzes across various categories while tracking their progress through detailed performance analytics.

The application follows the **MVC architecture** and focuses on scalability, responsiveness, and an intuitive user experience.

---

## Features

### User

* Secure account registration and authentication
* Create and manage personal profile
* Attempt quizzes from multiple categories
* Choose quiz difficulty and number of questions
* View real-time scores and quiz results
* Track quiz history and performance analytics

### Learning Experience

* Multiple quiz categories
* Difficulty-based quizzes
* Timed quiz sessions
* Instant result evaluation
* Leaderboards
* Experience Points (XP)
* Achievements and badges
* Daily challenges
* Personalized dashboard

### Administrator

* Manage quiz questions
* Manage quiz categories
* Monitor platform activity
* Update and maintain quiz content

### General

* Authentication and Authorization
* Responsive Design
* MVC Architecture
* CRUD Operations
* MongoDB Database Integration
* Server-side Rendering with EJS

## Installation

Clone the repository.

```bash
git clone https://github.com/your-username/Quizo.git
```

Move into the project directory.

```bash
cd Quizo
```

Install dependencies.

```bash
npm install
```

Create a `.env` file.

```env
ATLAS_URL=your_mongodb_connection_string
SESSION_SECRET=your_secret_key
```

Run the application.

```bash
npm start
```

or

```bash
nodemon app.js
```

Open your browser.

```text
http://localhost:3000
```
