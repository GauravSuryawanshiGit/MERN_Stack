# MERN_Stack

## Description

This repository contains major projects developed using the MERN stack during my full-stack development journey.

The projects focus on building practical web applications using MongoDB, Express.js, Node.js, EJS, JavaScript, and related technologies.

The repository contains three major projects:

- Quizo
- FarmConnect
- CarbonCalc

Each project is maintained in a separate directory with its own source code, dependencies, assets, and project documentation.
