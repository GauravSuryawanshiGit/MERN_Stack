# Carbon Footprint Calculator

<p align="center">

**Measure Your Carbon Footprint. Build Sustainable Habits.**

A full-stack web application that estimates carbon emissions based on everyday activities and provides users with meaningful insights to help reduce their environmental impact.

</p>

---

## Overview

The Carbon Footprint Calculator is a web application built using **Node.js, Express.js, MongoDB, and EJS** that helps users understand how their daily lifestyle contributes to carbon emissions. The application calculates emissions from common activities such as electricity consumption, transportation, household size, and food habits, then presents a clear summary along with recommendations for reducing environmental impact.

The project focuses on promoting environmental awareness through a simple, interactive, and user-friendly experience.

## Installation

Clone the repository.

```bash
git clone https://github.com/your-username/Carbon-Footprint-Calculator.git
```

Navigate to the project directory.

```bash
cd Carbon-Footprint-Calculator
```

Install the required dependencies.

```bash
npm install
```

Create a `.env` file in the project root.

```env
ATLAS_URL=your_mongodb_connection_string
SESSION_SECRET=your_secret_key
```

Run the application.

```bash
npm start
```

or

```bash
nodemon app.js
```

Open your browser.

```text
http://localhost:3000
```
