# FarmConnect

<p align="center">

**Connecting Farmers Directly with Consumers**

A full-stack web application that enables farmers to manage and showcase their agricultural products while providing consumers with a simple and transparent marketplace for discovering fresh produce.

</p>

---

## Overview

FarmConnect is a full-stack web application built using **Node.js, Express.js, MongoDB, and EJS**. The project aims to bridge the gap between farmers and consumers by providing a centralized platform where farmers can list agricultural products and consumers can explore them through a clean and user-friendly interface.

The application follows the **MVC architecture** and focuses on scalability, maintainability, and an intuitive user experience.

---

## Features

### Farmer

* Secure account registration and authentication
* Add new product listings
* Update existing products
* Delete products
* Manage personal product listings

### Consumer

* Register and log in securely
* Browse products from different farmers
* View detailed product information
* Explore products through a responsive interface

### General

* Authentication and Authorization
* CRUD Operations
* MVC Architecture
* Responsive Design
* MongoDB Database Integration
* Server-side Rendering with EJS

## Installation

Clone the repository.

```bash
git clone https://github.com/your-username/FarmConnect.git
```

Move into the project directory.

```bash
cd FarmConnect
```

Install dependencies.

```bash
npm install
```

Create a `.env` file.

```env
ATLAS_URL=your_mongodb_connection_string
SECRET=your_secret_key
```

Run the application.

```bash
npm start
```

or

```bash
nodemon app.js
```

Open your browser.

```text
http://localhost:3000
```
